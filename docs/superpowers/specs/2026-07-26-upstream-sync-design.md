# Upstream Sync Design

## Goal

Bring useful structure and behavior from `macqueen0987/SteamyRain` `main`
into the local skin without publishing changes or replacing local user data.

## Source of truth

- Upstream supplies project structure, static Rainmeter skin files, fonts,
  documentation, spacing meters, scan behavior, and image fallback behavior.
- Local files supply machine-specific paths, window/layout preferences,
  discovered game data, non-Steam entries, and user-provided images.
- Local UTF-8 handling and the stricter case-sensitive config parser remain
  where they do not conflict with upstream behavior.

## Files and behavior

Restore upstream static files including README, ignore rules, font resources,
Gap meters, `GapBetweenTiles`, and their matching Rainmeter styles.

Merge `UpdateGames.pyw` rather than replacing it:

- retain explicit UTF-8 reads and writes;
- retain robust Rainmeter config parsing;
- restore clear per-library result accumulation;
- exclude Steam compatibility/runtime entries;
- restore JPG/PNG image lookup across all upstream image names;
- restore fallback to another available image;
- restore scan progress updates;
- restore Gap meter generation.

Preserve these local data files and values:

- `@Resources/GamesInfo.inc`;
- `@Resources/NonSteamGames.inc`;
- machine paths, locale, mode, position, visibility, sizing, and color values
  in `@Resources/SkinInfo.inc`;
- generated dynamic meter files until regenerated by verification;
- local images under `@Resources/img`.

## Error handling

Scanner changes should tolerate missing image candidates and avoid producing an
invalid `ImageName`. Missing library directories should be reported through the
existing Rainmeter status mechanism instead of silently corrupting output.

## Verification

- Compile `UpdateGames.pyw` with Python.
- Run a fixture-style scanner check against temporary Steam manifest and image
  directories, without invoking Rainmeter or overwriting user data.
- Check all Rainmeter variable references for missing renamed variables.
- Compare the final static source set with upstream and confirm remaining
  differences are intentional local preservation or merged improvements.

## Non-goals

- No GitHub push or other remote mutation.
- No automatic Epic, Xbox, or Ubisoft scanning in this sync.
- No replacement of local game entries, executable paths, or images.
